# Indian Equity Research

This repository contains an Indian equity research internship project focusing on market data analysis, pipeline automation, and SQL-based analytics.

## Project Structure

- `docs/`
  - contains dashboard assets and visual reports for equity research
- `notebooks/`
  - exploratory and analysis notebooks covering market updates, trade deltas, security updates, and sector/industry lookup
- `pipeline/`
  - data ingestion and transformation notebooks for NSE/BSE bulk, block, trade, security, and market cap updates
- `sql/`
  - SQL queries for anomaly detection, data validation, and EDA on price momentum, breakout strength, and market deals

## Key Workflows

- `notebooks/01_data_exploration.ipynb` — initial data exploration
- `notebooks/04_data_preprocessing.ipynb` — preprocessing and cleaning steps
- `pipeline/` notebooks — optimized daily ingestion and delta processing for market sources
- `sql/` scripts — analytical queries for anomaly detection and market research validation

## Getting Started

1. Open this repository in VS Code.
2. Use the Jupyter extension to run the notebooks interactively.
3. Ensure you have Python and Jupyter installed.
4. Provide the required data sources before executing pipeline notebooks.

## Notes

- Data files are not included here.
- Update the notebooks and SQL scripts with your own file paths and data connections as needed.
- This repository is intended for research, analysis, and pipeline development for Indian equity market data.
